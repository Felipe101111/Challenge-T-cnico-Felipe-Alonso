# 🎮 JuegoContador

Juego simple hecho en React donde el objetivo es hacer la mayor cantidad de clicks en 5 segundos.

🎮 Cómo jugar
Presionar el botón Iniciar
Esperar la cuenta regresiva:
Preparados
Listos
Ya
Clickear lo más rápido posible durante 5 segundos
Intentar superar el puntaje máximo

🧱 Estructura
App.jsx: lógica principal del juego
main.jsx: punto de entrada
styles.css: estilos
index.html: base HTML

🛠️ Tecnologías usadas
React
Vite
JavaScript
CSS
